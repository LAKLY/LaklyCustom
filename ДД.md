# LaklyCustom — концепция утилиты для локального запуска комнат (v2.0)

## 1. Суть идеи

**LaklyCustom** — это лёгкое кроссплатформенное приложение, превращающее компьютер хоста в локальный сервер для совместных активностей. Хост запускает программу, нажимает «Создать комнату» — и она мгновенно становится доступна в интернете. Друзьям не нужно ничего устанавливать: они открывают ссылку или сканируют QR-код в браузере и сразу подключаются.

Это не только игры. LaklyCustom — универсальная платформа для проведения любых совместных онлайн-сессий:
- **Игры и развлечения:** мини-игры, квизы, викторины, «Мафия», «Бункер».
- **Совместная работа:** общие доски, голосования, текстовые редакторы.
- **Образование:** тестирование, опросы, интерактивные лекции.
- **Разработка:** быстрый показ локальных веб-приложений (Node.js, Python, статические сайты).

**Ключевая идея:** платформа работает по принципу «Local-first». Вся логика и данные находятся на компьютере хоста, туннель лишь пробрасывает трафик. Никаких сторонних серверов, подписок и обязательных аккаунтов.

---

## 2. Главные принципы

1.  **Zero-install для гостей:** гостям нужен только браузер.
2.  **Один клик для хоста:** создание комнаты, получение ссылки и QR-кода — мгновенно.
3.  **Local-first и приватность:** все данные сессии живут только на ПК хоста и исчезают после закрытия комнаты.
4.  **Модульность и расширяемость:** функциональность наращивается через плагины.
5.  **Кроссплатформенность:** Windows, macOS, Linux.
6.  **Низкий порог входа:** никаких регистраций, карт и сложных настроек роутера.
7.  **Универсальность:** поддержка как встроенных плагинов, так и проксирования любых локальных серверов.

---

## 3. Роли

*   **Хост:** создаёт комнату, управляет лобби, запускает активности, может кикать игроков и закрывать комнату.
*   **Гость:** подключается по ссылке, вводит имя, участвует в активностях.
*   **Наблюдатель (опционально):** может смотреть, но не участвовать.

---

## 4. Пользовательский путь

### Хост
1.  Скачивает и запускает приложение (установщик или портативная версия).
2.  Видит минималистичный интерфейс с кнопками «Создать комнату», «Настройки», «Плагины».
3.  (Опционально) Выбирает плагин для комнаты из списка установленных.
4.  Нажимает «Создать комнату». Приложение:
    *   Поднимает локальный сервер.
    *   Открывает безопасный туннель в интернет.
    *   Показывает публичную ссылку, QR-код и панель управления.
5.  Управляет комнатой: видит список игроков, чат, кнопки «Старт»/«Стоп» для игры, «Кик».

### Гость
1.  Переходит по ссылке или сканирует QR-код.
2.  Вводит своё имя.
3.  Мгновенно попадает в лобби или сразу в активную игру.
4.  Взаимодействует в реальном времени.
5.  При закрытии комнаты видит соответствующее уведомление.

## 5. Архитектура

### Компоненты системы

```
LaklyCustom (ПК хоста)
├── Ядро (Node.js + Electron)
│   ├── HTTP-сервер (Fastify)      # Быстрый и современный
│   ├── WebSocket-сервер (Socket.io) # Реалтайм-связь
│   ├── Менеджер комнат (RoomManager) # Управление жизненным циклом комнат
│   ├── Менеджер плагинов (PluginLoader) # Загрузка, установка, событийная шина
│   ├── Менеджер туннелей (TunnelManager) # Управление туннелями с fallback
│   └── Локальная панель хоста (UI) # Electron-окно
├── Плагины (расширяемая система)
│   ├── clicker
│   ├── quiz
│   └── ... (устанавливаются пользователем)
└── Интерфейсы
    ├── Окно хоста (Electron)     # Панель управления
    └── Гостевая страница (браузер) # Мобильный-first
```

### Технологии

| Слой | Технология | Обоснование |
|------|-----------|-------------|
| **Runtime** | Node.js | Единый язык для сервера и клиента. |
| **HTTP-сервер** | **Fastify** | В 3-4 раза быстрее Express, встроенная валидация схем, отличная поддержка WebSocket. |
| **Real-time** | Socket.io | Стандарт для реалтайм, широкая экосистема, автоматический fallback. |
| **Десктоп** | Electron | Кроссплатформенность, мощная экосистема, зрелость. |
| **Туннели** | **Cloudflare Tunnel** (основной), ngrok, localhost | Бесплатный, без токена и аккаунта, надежный. |
| **QR-код** | qrcode | Простая генерация QR. |
| **Упаковка** | electron-builder | Создание установщиков и портативных версий. |
| **Плагины** | Событийная шина (Event Bus) | Гибкость, слабая связанность, динамическая загрузка. |

### Схема работы

```
[Телефон гостя] → https://xxxx.trycloudflare.com → [Туннель] → [Локальный сервер на ПК хоста] → [Плагин / Внешний сервер]
```

## 6. Режимы комнат

1.  **Native Room:** встроенный плагин LaklyCustom. Ядро управляет лобби, состоянием и логикой игры.
2.  **Proxy Room:** хост указывает порт локального приложения (например, `localhost:3000`). LaklyCustom создаёт туннель к этому порту, и гости видят то, что запущено у хоста.
3.  **Static Room:** хост выбирает папку с HTML/CSS/JS, и LaklyCustom раздаёт её как статический сайт.

## 8. UI/UX

**Стиль:** тёмный, минималистичный, с неоновыми акцентами. Логотип — буква «L» с точкой-индикатором «сервер активен».

**Окно хоста (Electron):**
- **Единый экран комнаты:** слева — панель управления (ссылка, QR, игроки), справа — область для игры и чат. Это избавляет от необходимости переключаться между вкладками.
- **Кнопка «Зайти как гость»:** открывает гостевую страницу в браузере, чтобы хост мог видеть то же, что и игроки.
- **Вкладка «Плагины»:** управление плагинами. Установка через перетаскивание ZIP-файла в окно или через диалог выбора файла.

**Гостевая страница (браузер):**
- Мобильный-first.
- Крупное поле для ввода имени.
- Лобби с плитками игроков.
- В игре — минимум кнопок, всё под большой палец.

## 9. Безопасность и приватность

- Комната существует только при открытом приложении хоста.
- Ссылка одноразовая: после закрытия туннеля она перестаёт работать.
- Пароль на вход (опционально).
- Лимит игроков.
- Возможность кикнуть игрока.
- Никаких загрузок файлов на сервер хоста, если плагин это не разрешает.
- **Безопасность Electron:** обязательное использование `contextIsolation`, отключение `nodeIntegration`, валидация всех IPC-сообщений.

## 10. Плагинная система (Plugin API)

Плагин — это папка с двумя частями: `index.js` для серверной логики и `public/` для клиентского интерфейса.

```
plugins/clicker/
├── index.js          # Серверная логика (hooks)
└── public/
    └── game.html     # UI игры
```

### Как работает связь

```
┌─ Родитель (хост-панель или гостевая страница) ────┐
│  • держит Socket.IO соединение с сервером          │
│  • принимает game:state от сервера                  │
│  • передаёт action'ы кликов в сервер                │
│                                                     │
│  ┌─ iframe (game.html) ──────────────────┐          │
│  │  • НЕ имеет своего socket              │          │
│  │  • получает init + state через         │          │
│  │    window.postMessage                  │          │
│  │  • отправляет action'ы через postMessage│         │
│  └────────────────────────────────────────┘          │
└─────────────────────────────────────────────────────┘
```

### postMessage-протокол

| Сообщение | Откуда → куда | Что значит |
|-----------|---------------|-----------|
| `lakly:ready` | iframe → parent | Игра загрузилась, готова принимать данные. |
| `lakly:init` | parent → iframe | `{ player }` — кто играет. |
| `lakly:state` | parent → iframe | `{ data }` — состояние от плагина. |
| `lakly:action` | iframe → parent | `{ action, data }` — действие игрока. |

### Плагин на сервере

Плагин экспортирует объект с полем `hooks`, где ключ — это имя события, а значение — функция-обработчик.

```js
// plugins/clicker/index.js
import { EVENTS } from '../../shared/events.js';

const state = new Map(); // roomId -> { count, scores: Map }

export default {
  name: 'clicker',
  version: '1.0.0',
  description: 'Общий счётчик кликов: все игроки наращивают счёт вместе.',

  hooks: {
    [EVENTS.ROOM_CREATED]: ({ room }) => {
      state.set(room.id, { count: 0, scores: new Map() });
    },

    [EVENTS.GAME_START]: ({ room }) => {
      const s = getState(room.id);
      s.count = 0;
      s.scores = new Map();
      room.broadcast(EVENTS.GAME_STATE, {
        count: s.count,
        leaderboard: leaderboard(s),
      });
    },

    [EVENTS.PLAYER_JOINED]: ({ room, socket }) => {
      if (!room.gameActive) return;
      const s = getState(room.id);
      socket.emit(EVENTS.GAME_STATE, {
        count: s.count,
        leaderboard: leaderboard(s),
      });
    },

    [EVENTS.GAME_ACTION]: ({ room, player, action }) => {
      if (action !== 'click') return;
      const s = getState(room.id);
      s.count++;
      const prev = s.scores.get(player.name) || 0;
      s.scores.set(player.name, prev + 1);

      room.broadcast(EVENTS.GAME_STATE, {
        count: s.count,
        leaderboard: leaderboard(s),
        lastClick: { name: player.name, color: player.color },
      });
    },
  },
};
```

### Установка плагина

1.  Пользователь перетаскивает ZIP-архив в окно на вкладке «Плагины».
2.  Electron распаковывает архив в `plugins/<name>/`.
3.  `PluginLoader.load()` перечитывает папку, регистрирует hooks.
4.  Плагин появляется в списке и в выпадающем меню комнаты.

## 12. Риски и решения

| Риск | Решение |
|------|---------|
| **Туннель требует токен** | Cloudflare Quick Tunnel работает без аккаунта. Fallback на ngrok и localhost. |
| **Блокировки в РФ** | Несколько туннель-провайдеров + собственный релейный сервер в будущем. |
| **Антивирус ругается на `.exe`** | Собрать портативный ZIP, позже купить подпись кода. |
| **Windows Firewall** | При первом запуске понятная инструкция «Разрешить доступ». |
| **Хост выключил ПК** | Комната закрывается, гости видят уведомление. |
| **Слабый ПК хоста** | Ограничение на 10–20 игроков, лёгкие плагины. |
