LaklyCustom 0.8.0

Plugin-driven платформа для локальных комнат.

Режимы: чат с плагинами, статика из папки, проксирование локального порта.

Публичная ссылка создаётся через Cloudflare Quick Tunnel — без токена.

Приложение продолжает работать в трее, даже когда окно закрыто.
